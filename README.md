# map-models

Low-poly 3D-модели для Spectr.Map: деревья и кусты для парков и лесов.

## Состав

| Папка | Модели | Группа |
|---|---|---|
| `trees/` | `tree_default`, `tree_oak`, `tree_fat`, `tree_simple` | лиственные (`deciduous`) |
| `trees/` | `tree_pineRoundA`, `tree_pineSmallA` | хвойные (`pine`) |
| `bushes/` | `plant_bushLarge` | кусты (`bush`) |

Все модели — glTF (`.glb`), по 5–15 КБ.

## manifest.json

- `models` — путь, группа и диапазон высоты в метрах для каждой модели.
- `colors` — цвета частей (крона, тёмная крона, ствол) для тёмной и светлой темы. Цвета взяты из палитр Spectr.Map (grey-2, grey-3).
  Модели хранятся в оригинальных цветах — перекраска происходит при отрисовке.
- `parts` — как по имени материала определить часть модели (ствол / тёмная крона / крона).
- `placement` — правила расстановки:
  - `minzoom` — с какого зума показывать;
  - `wood` / `grass` — шаг сетки (м) и доли групп для лесов и газонов/парков;
  - `clearance` — отступ от дорог по классам (м);
  - `maxInstances` — максимум деревьев на экране.

## Как подключено

Деревья ставятся по полигонам `landcover` (классы `wood` и `grass`) из тайлов OpenMapTiles
на детерминированной сетке: при перемещении карты деревья не «прыгают».
Точки внутри зданий и рядом с дорогами пропускаются. Отрисовка — three.js custom layer
с instancing (одна модель — один draw call на часть).

Демо: `3d-preview/trees.html` в папке проекта (запуск через `python -m http.server 8080`).

## Публикация

Репозиторий рассчитан на GitHub Pages. После включения Pages модели подключаются так:
`trees.html?models=https://solokns.github.io/map-models/`
